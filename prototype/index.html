界面原型 · 第 4 版

这一版加上了你选的 4 个 Codex 功能（标 新），自定义模式改名为 Skills 配置。原型不连接 Claude，能点的地方都可以点。示例里的 GitHub 仓库是真实存在的，对话是虚构的。

  1. 左栏：按项目分组的对话。proj → 为项目挑选 Skills 和工具 是 Skills 配置模式的完整示例
  2. 活动记录：读文件、跑命令都只占一行，点开看详情
  3. 代码改动：红色是删掉的行，绿色是新增的行
  4. 审批框：试试「允许一次 / 总是允许 / 拒绝」
  5. 模式菜单：Claude Code 自带 4 个 + 自定义的 Skills 配置；Shift+Tab 切换
  6. 模型选择器：模型、思考强度、速度
  7. Git 审查和提交：按范围看改动；鼠标移到某一行点 + 写评论发给 Claude；暂存、撤销、提交、推送、开 PR 新
  8. Worktree：点「新对话」，在输入框下方选「新 worktree」，这个对话就在独立的工作区里跑。web-app → 修复登录页样式错位 正在 worktree 里并行运行 新
  9. 内置终端：顶部的「终端」按钮，或按 Ctrl+` 新
  10. 自动化：左栏的「自动化」，可以看审查队列、新建定时任务 新

黄色数字可以用左下角的 ● 按钮关掉，旁边的 ☾ 切换深色 / 浅色。

Skills 配置模式 自定义

按项目需求挑选合适的 Skills 和工具（MCP）。Claude 按这个顺序做：了解项目（读 README、依赖和你的描述）→ 盘点已安装的 Skills 和工具 → 上 GitHub 和 Skills 目录搜索缺的 → 给出推荐清单让你勾选 → 安装、保留、关闭 → 记进 CLAUDE.md。

直接执行

  • 读取项目文件
  • 列出已安装的 Skills、插件和 MCP 服务器
  • 在 GitHub、Skills 目录、插件市场搜索
  • 读取候选的 SKILL.md 和文件清单（只看，不运行）

在推荐清单里确认

  • 安装新 Skill（装到项目的 .claude/skills/）
  • 添加 MCP 服务器（项目级 .mcp.json）
  • 在本项目保留或关闭 Skills、插件（写 .claude/settings.json）
  • 含脚本的 Skill：先列出脚本给你审查
  • 装到用户级（对所有项目生效）：单独确认

一律拦截

  • 运行下载来的 Skill 里的脚本
  • 改源代码、装依赖等其他操作（请切到别的模式）
  • 保底黑名单里的高危操作

候选的筛选标准：有许可证、一年内有更新、star 数不太低，官方出品的优先。搜索来源和筛选标准都可以在 设置 → 权限与模式 里改。
